# BetterU
A simple CLI based app to track things that you need to get done to better yourself with a reward system and priority system to help you meet your goals and reward yourself for them.
To use simply run the script from your command line terminal.
From the directory you have saved the betteru.py script type python3 betteru -h to view the help screen.
You can also use the -h flag with any of the functions of the app for help with that function.
